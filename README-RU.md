# 404 Team — лендинг с атрибуцией

Готовая версия лендинга с серверной аналитикой, уникальными ссылками и скрытой админ-панелью.

## Что работает

- уникальные ссылки вида `https://ваш-домен/?ref=tiktok-2`;
- закрепление первой метки за посетителем на 90 дней;
- просмотры, уникальные посетители и клики по каждой кнопке;
- разбивка по подписи, источнику, аккаунту и кампании;
- журнал последних событий и периоды 7/30/90 дней или всё время;
- создание и отключение ссылок, копирование готового URL;
- изменение целевых адресов кнопок;
- серверные уведомления в Telegram по каждому клику;
- открытие админ-панели сочетанием `Ctrl + Shift + H`.

## Защищённые переменные

Секреты нельзя добавлять в HTML или репозиторий. На сервере должны быть заданы:

- `ADMIN_LOGIN` — логин администратора;
- `ADMIN_PASSWORD` — пароль администратора;
- `SESSION_SECRET` — длинная случайная строка для подписи сессий и атрибуции;
- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота;
- `TELEGRAM_CHAT_ID` — ID канала или чата.

Имена переменных есть в `.env.example`, значений в исходниках нет.

## Локальная проверка

1. Установить зависимости: `npm ci`.
2. Создать миграцию после изменения схемы: `npm run db:generate`.
3. Собрать: `npm run build`.
4. Применить миграцию к локальной D1-базе командой из раздела Local D1 migrations в основном `README.md`.
5. Запустить: `npm start`.

Для полноценного использования нужен хостинг с Cloudflare Workers и D1 либо OpenAI Sites. Обычный статический HTML не может безопасно хранить общую статистику, пароль администратора и токен Telegram.
